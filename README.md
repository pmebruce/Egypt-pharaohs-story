# 古埃及史：法老與時代（約 3150 BCE — 30 BCE）

參考 `us-presidents-story` 架構打造的繁體中文古埃及法老歷史互動導覽網站，涵蓋 8 大歷史時期與 17 幕代表性法老。

## 部署至 GitHub Pages

1. 在 GitHub 建立新儲存庫（例如 `egypt-pharaohs-story`），設為 **Public**。
2. 將本專案中的 `index.html`、`README.md` 與 `assets/` 資料夾上傳（或 `git push`）至 `main` 分支根目錄。
3. 前往儲存庫的 **Settings → Pages**，在 **Build and deployment** 選擇 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)` 並儲存。
4. 等待約 1–2 分鐘，即可透過 `https://<你的帳號>.github.io/<儲存庫名稱>/` 瀏覽。
